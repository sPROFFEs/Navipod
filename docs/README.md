## Documentation principles

- Keep the root `README.md` short enough to scan.
- Put command-heavy or deployment-specific instructions here.
- Treat `.env.example` and deployment templates as the source of truth when configuration changes.
- Never place real credentials, cookies, database files or private URLs in screenshots or examples.
